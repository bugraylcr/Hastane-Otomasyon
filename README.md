Bu repo, veritabanı destekli bir Hastane Otomasyonu projesini içermektedir.
Projede hasta, doktor, randevu ve kullanıcı işlemleri SQL Server ile yönetilmiştir.
Stored procedure, trigger, view ve fonksiyonlar aktif olarak kullanılmıştır.
Proje, hem ders gereksinimlerini karşılamak hem de pratik kazanmak amacıyla geliştirilmiştir.
İnceleyenler için anlaşılır ve geliştirilebilir bir yapı hedeflenmiştir.
